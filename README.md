## Things I Believe

- **A test set comes before the prompt.** If you can't measure accuracy, you're guessing.
- **Not every problem needs an LLM.** Sometimes a SQL query or a regex is the right answer, and I'll say so.
- **The boring parts are the product.** Access control, audit logs and cost limits decide whether AI reaches production.
- **Ship early, demo weekly.** A working version early beats a perfect plan late.
